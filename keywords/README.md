# Keywords

Internal Keyword Planner for Roster, at https://previews.heylead.com/keywords/

Singapore only (geo 2702). English, Chinese, and Malay. Ideas, exact volumes,
and a click/cost forecast. CSV download. Read only.

Backend: `~/heylead-keywords-api`
`https://heylead-keywords.martin-656.workers.dev`

The Google Ads refresh token is a Worker secret. The page token is not in this
repo. A connect link `#kw=` stores it in the browser and strips the hash.
