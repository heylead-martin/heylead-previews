How ApplyLab works (v1)

  1. Connect your Worker URL + APP_TOKEN in Settings.
  2. Fill Profile with resume text, skills, and target roles.
  3. Browse remote full-time jobs scored against your profile.
  4. Tailor resume + cover letter with xAI for a role you like.
  5. Apply on the job board (semi-auto: we prepare, you submit), then mark status in Tracker.

Inspired by AIApply - personal private build first. No form-fill bots yet.

Select a job to preview and tailor materials.

API connection

Worker holds your xAI key and profile data. Token never leaves this browser except as a header to your Worker.

Deploy checklist

  1. In ~/applylab-api: npx wrangler secret put APP_TOKEN
  2. npx wrangler secret put XAI_API_KEY (from console.x.ai)
  3. npx wrangler deploy
  4. Paste workers.dev URL + token here
  5. Save profile, refresh jobs, tailor a match
