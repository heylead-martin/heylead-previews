How ApplyLab works (v1)

  1. Connect Worker URL + APP_TOKEN in Settings (once per browser).
  2. Upload resume on Profile (PDF or TXT) + skills and target roles. Save once.
  3. Browse remote jobs from Remotive, Jobicy, and RemoteOK (scored to your profile).
  4. AI tailor on a job: rewrites your resume + cover letter from that job description.
  5. Apply yourself on the listing (semi-auto), copy materials, mark status in Tracker.

Job boards scanned: Remotive, Jobicy, RemoteOK. Cache refreshes about every 4 hours (or Refresh jobs).

API connection

Worker holds your xAI key and profile data. Token is stored only in this browser (localStorage). If the field looks empty, paste it again from ~/applylab-api/.app-token-local.txt - Saving with a blank field no longer wipes a saved token.

Deploy checklist

  1. In ~/applylab-api: npx wrangler secret put APP_TOKEN
  2. npx wrangler secret put XAI_API_KEY (from console.x.ai)
  3. npx wrangler deploy
  4. Paste workers.dev URL + token here
  5. Save profile, refresh jobs, tailor a match
