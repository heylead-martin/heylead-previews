Google Maps listings

Search Places for a trade and a city. You get name, phone, website, rating, and up to five review samples per listing. Google does not sell the full review history for other people's businesses.

Connect Places

  1. Open Google Maps Platform and enable Places API (New).
  2. Create an API key. Restrict it to Places API (New). Billing has to be on.
  3. Paste the key below. It stays in this browser. The Worker URL is already set.

Neither secret is in this public repo. The Worker also accepts GOOGLE_PLACES_API_KEY as a wrangler secret.

What this can and cannot do

  • Can: pull public Google Maps listings through Places API (New), including phone, website, rating, review count, and a five-review sample.
  • Cannot: download every review on a competitor. That cap is a Google product limit. Full review history exists only on a Business Profile you own.
  • Storage: Place IDs may be kept. Google forbids caching names, reviews, and similar fields. CSV is a working export for this session.
  • Attribution: listing and review data from Google. Powered by Google.
