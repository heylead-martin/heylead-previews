Методология и източници

Имоти BG е пазарна аналитика - не брокер и не банка. Графиките и изводите се градят върху публични API + ясни правила къде ползваме ориентири.

Данните са обновени 2026-08-11 (Eurostat, ECB MIR, FRED/BIS където е налично).

Снимка от последния real pull

  • Индекс жилища: 272,6 (+14,8% за 1 г.) - Eurostat
  • Ипотека: 2,48% - ECB MIR
  • Потребителски: 9,43% - ECB MIR
  • Депозити: 0,01% - ECB MIR

Какво е „реално“ и какво е ориентир

  • Реално (API): национален индекс на цените - Eurostat prc_hpi_q (данни от НСИ); ипотека/потребителски/депозити - ECB MIR за България; по избор дълга история - FRED/BIS; референция ECB - FRED ECBDFR.
  • Ориентир: €/м² по град и квартал, „обяви“, дни на пазара - локални нива и коефициенти, докато няма listings partner API.
  • Изводите на началната страница се генерират автоматично от реалните серии (1г / 5г / 10г промени, спред ипотека-потребителски, и т.н.).
  • Новини: показваме само заглавия с директен линк към статия. Шаблонни заглавия към начални страници на медии не се публикуват.

Продажби и наеми

URL режим: / = продажби, /naemi/ = наеми; градове/квартали с /prodazhbi/ или /naemi/. Брутна доходност ≈ 12 × наем / цена (без данъци и разходи).

Квартал срещу град

На всяка регионална страница: (1) две линии - средно за града и квартала; (2) премия с база град = 100. Кварталът = градски индекс × относителен коефициент - не отделна 30-год. официална серия на НСИ.

Бележки

  • Национален HPI: Eurostat prc_hpi_q (данни от НСИ), индекс 2015=100.
  • По-дълга BIS серия (по избор): FRED QBGN628BIS с FRED_API_KEY.
  • Лихви: ECB MIR за България (жилищни, потребителски, депозити) - без API ключ.
  • Преди началото на официалната серия остават seed/estimate точки.
  • Квартални €/м² са релативни нива, не официален NSI HPI по квартал.
  • Обяви live: само с LISTINGS_API_URL + KEY от партньор.

Източници

  • Eurostat - House price index (quarterly)

    https://ec.europa.eu/eurostat/databrowser/view/prc_hpi_q/default/table

    API: https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/prc_hpi_q

  • НСИ - Индекс на цените на жилищата (производител на националните данни)

    https://www.nsi.bg/

    API: Excel/CSV от сайта; Eurostat е машинният канал

  • ECB MIR - Bank interest rates Bulgaria

    https://data.ecb.europa.eu/data/datasets/MIR

    API: https://data-api.ecb.europa.eu/service/data/MIR/{key}?format=jsondata

  • FRED / BIS Residential Property Prices Bulgaria

    https://fred.stlouisfed.org/series/QBGN628BIS

    API: https://api.stlouisfed.org/fred/series/observations

  • БНБ - Лихвена статистика (първоизточник; ECB MIR е хармонизираният EU feed)

    https://www.bnb.bg/

    API: Публикации/таблици; няма стабилен безплатен JSON API като ECB

  • RSS новини (Capital, Investor.bg, …)

    scripts/fetch-news-delta.mjs

  • Listings partner API (optional)
